# 便签纸视觉重设计 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `frontend/` 的默认蓝白 Vant 皮肤换成「家庭标签 / 便签纸」视觉语言（暖纸底、墨褐字、陶土/苔绿点缀、衬线标题、贴纸标签、纸卡微旋转 + 硬边投影），功能与接口不变。

**Architecture:** 在 `src/styles/` 建立单一令牌源（`tokens.ts` 导出 Vant `themeVars` 与 `designTokens`；`global.css` 定义 CSS 变量与字体；新增 `paper.css` 承载共享纸感类与 Vant 覆盖）。各 `views/*.vue` 只改模板标记与 scoped 样式，复用共享类；图标统一走新增的 `PaperIcon.vue`。Vant 仍是组件基座。

**Tech Stack:** Vue 3 + TypeScript + Vant 4 + Vite 6 + Vitest 2。

**Spec:** `docs/superpowers/specs/2026-10-16-便签纸视觉重设计-design.md`

## Global Constraints

- 功能、路由、接口、数据模型**不变**；不改 `src/api/**` 的契约。
- 正文文字只能用 `--ink` / `--ink-2`（对纸底/纸卡 ≥4.5:1）；`--ink-3` 仅非文本。
- 破坏性/错误 = `--danger #A8391F`；暖色强调/临期 = `--terracotta #C2603C`；正向 = `--moss #6B7A4F`。
- 主操作按钮（创建/提交/保存/登录）= 墨色实心（Vant `primaryColor` 设为墨色）；「+新增」小按钮 = 陶土色贴纸。
- 圆角：卡片 `3px`、chip/按钮 `2px`；硬投影 `1px 2px 0 rgba(43,38,34,.08)`；微旋转 ≤2deg。
- 触摸目标 ≥44px；`prefers-reduced-motion` 必须生效；不得用 emoji 作结构图标。
- 离线部署：字体自托管（推荐 npm `@fontsource/noto-serif-sc`，仅引入 600/700 权重）。
- 现有 `npm run test`（vitest）与 `npm run build`（vue-tsc + vite）必须保持通过。

## Review Focus

1. **低对比度 12px 元信息**（列表 meta、占位、时间）—— 必须用 `--ink-2`，不得掉到 `--ink-3`；由 Task 1 的对比度测试守住。
2. **字体加载失败/子集缺字**（离线设备）—— 必须回退系统中文字体且布局不塌；Task 1 设置 `font-display: swap` + 完整 fallback 栈。
3. **reduced-motion** —— 关闭动画后纸卡仍可见、不依赖动画完成才出现；Task 2 复核全局规则。
4. **触摸目标 <44px**（小图标按钮、chip、开关）—— 视觉/交互验收；Task 12 的 E2E 覆盖关键操作。
5. **微旋转导致点击热区偏移或遮挡** —— 旋转只用于装饰性容器、`max 2deg`；Task 12 的 E2E 点击关键元素验证。

```ts
import { describe, it, expect } from 'vitest';
import { designTokens } from './tokens';

function srgb(c: number) {
  const s = c / 255;
  return s <= 0.03928 ? s / 12.92 : Math.pow((s + 0.055) / 1.055, 2.4);
}
function lum(hex: string) {
  const n = hex.replace('#', '');
  const r = parseInt(n.slice(0, 2), 16);
  const g = parseInt(n.slice(2, 4), 16);
  const b = parseInt(n.slice(4, 6), 16);
  return 0.2126 * srgb(r) + 0.7152 * srgb(g) + 0.0722 * srgb(b);
}
function contrast(a: string, b: string) {
  const L1 = lum(a);
  const L2 = lum(b);
  const hi = Math.max(L1, L2);
  const lo = Math.min(L1, L2);
  return (hi + 0.05) / (lo + 0.05);
}

describe('paper design tokens', () => {
  it('defines required color tokens', () => {
    const keys = ['paper','card','note','ink','ink2','ink3','terracotta','terracottaSoft','moss','mossSoft','amber','line','dashed','danger'] as const;
    for (const k of keys) {
      expect(designTokens[k]).toMatch(/^#[0-9A-Fa-f]{6}$|^rgba\(/);
    }
  });

  it('body text meets 4.5:1 on paper and card', () => {
    for (const bg of [designTokens.paper, designTokens.card]) {
      expect(contrast(designTokens.ink, bg)).toBeGreaterThanOrEqual(4.5);
      expect(contrast(designTokens.ink2, bg)).toBeGreaterThanOrEqual(4.5);
    }
  });

  it('ink3 is reserved for non-text (under 4.5:1)', () => {
    expect(contrast(designTokens.ink3, designTokens.paper)).toBeLessThan(4.5);
  });
});
```
