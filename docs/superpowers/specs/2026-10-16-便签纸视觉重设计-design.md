# 家庭收纳 · 便签纸视觉重设计（前端）— 设计文档

- 日期：2026-10-16
- 范围：前端（`frontend/`，Vue 3 + Vant 移动优先）
- 状态：待审批

## 背景与意图（为什么做）

现有前端配色为默认 Web 蓝（`#2563EB`）+ 白底 + 圆角软阴影卡片 + 系统字体栈，属于典型的「默认组件库 / AI 生成」观感：白底蓝主色、通用字体、无场景个性。这与「家庭收纳」这个生活化主题脱节。

本次把它换成**「家庭标签 / 便签纸」**视觉语言：暖白纸底、墨褐文字、陶土橙与苔绿点缀、有纸感的衬线标题、贴纸式标签、纸卡微旋转 + 硬边投影。目标是让它像**一本用旧的家庭记录本 / 橱柜标签系统**，温暖、可信、有生活气——而不是一个组件库 demo。

## 目标

- 建立一套完整的「便签纸」设计令牌（颜色 / 字体 / 形状 / 投影 / 动效 / 图标）。
- 全站视觉一致：登录、注册、主布局(NavBar+Tabbar)、首页、物品列表/详情/新增·编辑、购物、我的、设置、成员管理、位置管理。
- 用**统一 SVG 线性图标**替换 emoji 与默认图标（emoji 不得作为结构图标）。
- 无障碍不回退：文本对比度、键盘焦点可见、触摸目标 ≥44px、`prefers-reduced-motion` 生效。

## 非目标

- 不改后端、接口、数据库、路由与页面职责；不新增/删减功能。
- 本次**不做暗色主题**（结构上为将来留口，但不实现）。
- 不引入新的 UI 框架；继续以 Vant 为组件基座。

## 反目标（anti-goals，即使「能用」也算失败）

- 怀旧到影响可读性 / 信息密度——纸感不能牺牲可用性。
- 用 emoji 当导航/操作图标；回到白底蓝渐变那套。

## 约束

- **离线部署，无 CDN**：字体必须自托管。
- 移动优先（微信 / 手机浏览器），触摸目标 ≥44px。
- Vant 主题经 CSS 变量 + 定向覆盖实现；组件**语义与交互逻辑保持不变**。

## 已决定的「怎么做」

1. **视觉方向**：便签纸（**不使用胶带**；靠纸色 + 微旋转 + 硬边投影 + 虚线表达）。
2. **字体**：**打包一款中文衬线子集**用于标题/数字（正文用系统中文字体栈）。→ 全端一致、纸感足；前端体积增加约 1–3 MB（子集后）。
3. **范围档位**：②**换皮 + 微调结构**（功能与接口不变，完成后跑一次 E2E 回归）。
4. **色彩语义**：陶土橙 = 主强调/警示（临期）；苔绿 = 正向（在库/位置）；便签黄 = 仅关键提示模块（临期提醒）。

## 设计令牌（spec）

### 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F6F1E7` | 页面底色 |
| `--card` | `#FFFDF8` | 纸卡 |
| `--note` | `#FBF3D5` | 便签黄（仅临期等关键模块） |
| `--ink` | `#2B2622` | 主文字 |
| `--ink-2` | `#6E655A` | 次要文字 |
| `--ink-3` | `#8A8072` | **仅非文本**（边框/装饰图标）；不用于正文文字 |
| `--terracotta` | `#C2603C` | 强调 / 警示（临期；及「+新增」贴纸标签） |
| `--terracotta-soft` | `#FBEFE6` | 警示底 |
| `--danger` | `#A8391F` | 破坏性 / 错误（删除、超量报错） |
| `--moss` | `#6B7A4F` | 正向 |
| `--moss-soft` | `#E9EEDD` | 正向底 |
| `--amber` | `#C99A3B` | 中性强调（如「初始」记录） |
| `--line` | `rgba(43,38,34,.14)` | 实线分隔 |
| `--dashed` | `rgba(43,38,34,.35)` | 虚线/描边 |

> 对比度：`--ink`/`--ink-2` 对 `--paper`/`--card` 均需 ≥4.5:1（实施时用实际值核验）。**正文文字只用 `--ink` / `--ink-2`；`--ink-3` 不得承载文字信息**（其 ≈3.4:1 仅供非文本装饰）。

### 字体

- 标题 / 大数字：打包的**中文衬线**（display），字重 600–700。
- 正文 / 控件：系统中文字体栈（`PingFang SC, Microsoft YaHei, ...`）。
- 编号 / 时间等可选等宽（`ui-monospace` 或 Consolas）。

### 形状与投影

- 圆角：卡片 `3px`；chip / 按钮 `2px`（近乎直角，纸感）。
- 投影：`1px 2px 0 rgba(43,38,34,.08)`（纸卡）；关键卡 `2px 3px 0`。
- 微旋转：纸卡 `±0.4~0.8deg`；标签 chip `±1.5~2deg`（**上限 ~2deg**，避免廉价/影响对齐）。
- 间距：8px 系节奏。
- 纸纹：极淡的点阵（`radial-gradient`，`background-size` 约 5–7px），透明度 ≤5%，仅底色层。

### 动效

- 进入：纸卡「落下」错峰（`translateY` + 透明度，约 60ms 错峰）。
- 按压/hover：轻微位移或明度变化，**不改变布局边界**。
- 全站尊重 `prefers-reduced-motion`（已有全局规则，保留）。

### 图标

- 单套 SVG 线性图标，统一线宽（1.5–2px）与端点风格，替换 Vant 默认图标与 mockup 中的 emoji（如 🔍、🧺）。
- 装饰性图标 `aria-hidden="true"`；独立图标控件提供可访问名。

### 组件改造要点

- **NavBar / Tabbar**：纸底 + 虚线分隔；选中态用墨色。
- **卡片**（统计/物品/购物）：纸卡 + 硬投影 + 轻旋转。
- **贴纸标签 chip**：分类 = 纸色虚线；位置 = 苔绿虚线；临期/警示 = 陶土。
- **便签黄卡**：仅用于「临期提醒」这类需要跳出的模块。
- **按钮**：主操作（创建 / 提交 / 保存 / 登录）= **墨色实心**（盖章感）；次操作 = 纸白描边；陶土橙仅用于警示（临期）与「+ 新增」小贴纸标签；破坏性操作（删除 / 错误）= **深砖红 `--danger`**。
- **表单**：下划线/虚线分隔的纸张感；覆盖 Vant field / stepper / calendar / dialog 的默认皮肤。

### 逐屏（②范围内的结构微调）

- 登录 / 注册：纸背景 + 衬线标题 + 便签卡表单。
- 首页：统计纸卡组 + 临期便签 + 维度统计纸条；Tabbar 纸底。
- 物品列表：虚线搜索 + 筛选标签 + 纸卡列表（微错落）。
- 物品详情：主便签（名称 + 临期戳）+ 字段网格 + 库存历史「小纸条」堆叠 + 盖章式出入库。
- 物品新增 / 编辑：纸面表单。
- 购物：状态标签 + 纸卡 + 勾选。
- 我的：纸卡 + 菜单组。
- 设置 / 成员 / 位置：纸面列表 + 底部操作。

## 验收标准

- **视觉**：全站不再出现默认蓝白；关键页面截图与本文令牌一致（token 值与截图一并留档）。
- **无障碍**：正文对比度 ≥4.5:1；焦点可见；触摸目标 ≥44px；`reduced-motion` 生效；无 emoji 结构图标。
- **回归**：`cd frontend && npm run test`（vitest）与 `npm run build`（`vue-tsc`）通过；Playwright E2E 核心流程无回退。
- **证据**：截图/报告落 `docs/e2e/` 或 `docs/superpowers/`。

## 复核决议（builder check 后定稿）

- **文字与对比度**：正文文字只用 `--ink` / `--ink-2`（均 ≥4.5:1）；`--ink-3` 仅非文本（边框/装饰图标）。12px 元信息/占位文字一律用 `--ink-2`，不得用 `--ink-3`。
- **破坏性/错误色**：独立 `--danger #A8391F`（深砖红），用于删除、超量报错等；与陶土橙（暖色强调/临期）区分，保证「删除」与「主强调」一眼可分。
- **按钮色阶**：主操作（创建/提交/保存/登录）= 墨色实心；次操作 = 纸白描边；陶土橙 = 警示 + 「+新增」贴纸标签；破坏性 = `--danger`。
- 其余细节见下方「留给实施者的决定」。

## 留给实施者的决定（builder calls，非用户需答）

- 中文衬线**具体选型**（思源宋体 Noto Serif SC / 霞鹜文楷 LXGW WenKai 等）与子集化方式（如 `pyftsubset`）。
- 哪些 Vant 组件保留默认外观、哪些自定义替换（tabbar / calendar 等）。
- 微旋转的精确角度与适用范围；照片占位的纸张化处理。
- 图标集的具体来源与命名。

## 风险

- 打包字体体积；子集漏字会回退系统字（可接受）。
- Vant 深度覆盖的 CSS 特异性问题。
- 微旋转可能影响对齐与点击热区——需 E2E 验证。
